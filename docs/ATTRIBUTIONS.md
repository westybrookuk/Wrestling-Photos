- Keys are stable source ids, never display names. Two identities that share a photo keep separate rows.
- Photographed rows are matched to identities by **stable id**; the name index exists only for the few strings in the game that carry no id (the development-coach pool, owner labels, commentary fallbacks).
- Ambiguous names are deliberately left unindexed. The name "Arturo Rivera" is the worked example: the canonical file under that name is a self-portrait by a Mexican painter, a different person.
